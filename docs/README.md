# BTMS documentation

New to BTMS? Start with [Getting started](getting-started.md): it goes from the download to a map
on your website.

| Guide | Read it when you want to |
|---|---|
| [Getting started](getting-started.md) | install BTMS, set up the keys, render a first zone and the whole map, publish it, update it |
| [Configuration](configuration.md) | change what is drawn: every key of `map.toml`, server resources, lighting, water |
| [Command line](cli.md) | run BTMS from a terminal or a script: every command, option and environment variable |
| [Interface](interface.md) | know what every part of the interface does |
| [Tile format](tile-format.md) | use the tiles in your own map: the grid, the files, `tiles.json`, Leaflet and OpenLayers |
| [Architecture](architecture.md) | understand how BTMS reads the game and draws the map, or work on the code |
| [Troubleshooting](troubleshooting.md) | fix missing keys, an unused graphics card, holes, refused updates and other problems |

## Quick answers

- **The keys:** [Getting started, step 3](getting-started.md#3-import-the-keys).
- **Adding your server's resources:** [Configuration, `[resources]`](configuration.md#resources).
- **Putting the map on a website:** [Getting started, step 8](getting-started.md#8-put-the-map-on-a-website).
- **Something went wrong:** [Troubleshooting](troubleshooting.md), then
